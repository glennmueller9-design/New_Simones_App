# Purzelhuus Menüplaner Pro

Enthalten:
- vollständiger Menüpool aus den auslesbaren Menüplänen ohne Dubletten
- mindestens 50 zusätzliche Vorschläge pro Kategorie
- Eingabemaske für neue Menüs direkt in der Web-App
- lokale Speicherung im Browser/iPhone
- Export/Import der Datenbank
- CSV-Export des Wochenplans
